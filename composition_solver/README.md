# Решатель ОДУ на композиционных схемах с комплексными коэффициентами

Python 3, зависимости: `numpy`, `scipy` (только эталонные решения), `matplotlib`.

```
csolver/base_methods.py   опорные методы 2-го порядка (комплексная арифметика)
csolver/compositions.py   композиционные схемы (коэффициенты γ_i)
csolver/solver.py         интегрирование с постоянным шагом, проекция Re после шага
csolver/problems.py       8 тестовых нежёстких задач
experiments/order_convergence.py   эксперимент 1: порядок сходимости + графики (~3.5 мин)
experiments/diagnostics.py         эксперимент 2: симметричность опор, проекция, nsub
experiments/stability_regions.py   вопрос 3: области устойчивости, A-устойчивость
experiments/conj_search.py         вопрос 3: поиск симметрично-сопряжённой схемы 6-го порядка
experiments/coeff_search.py        вопрос 4: поиск коэффициентов для несимметричной опоры (~12 мин)
experiments/verify_found.py        вопрос 4: проверка найденных схем на ОДУ
experiments/failure_classes.py     вопрос 2: задачи, на которых схемы не работают
csolver/stability.py, csolver/order_conditions.py   устойчивость и условия порядка
results/                  csv, таблицы, графики
RESEARCH.md               ответы на вопросы 1–4
```

Пример:
```python
from csolver import integrate, BASE_METHODS, SCHEMES, problems
p = problems.van_der_pol()
r = integrate(p, BASE_METHODS["KD"], SCHEMES["P6C"], 100)   # 100 шагов на [0, 10]
print(r["y"], r["nf"])
```

## Что реализовано

**Опорные методы** (все порядка 2, шаг h может быть комплексным):

| метод | тип | симметричен | неявная часть |
|---|---|---|---|
| `trapezoid` | неявный | да | Ньютон по всей системе, комплексный |
| `KD` (s = 0.5) | полуявный: Эйлер–Кромер h/2 + D-метод h/2 в обратном порядке | да | скалярный Ньютон по каждой компоненте |
| `midpoint` | явная модифицированная средняя точка Грэгга, 2 подшага + сглаживающий шаг | **нет** (почти) | — |

**Композиции** Ψ_h = Φ_{γ_m h} ∘ … ∘ Φ_{γ_1 h}:

| схема | стадий | коэффициенты |
|---|---|---|
| P2 | 1 | сама опора |
| P3C | 2 | γ = 1/2 ± i/(2√3) (Σγ = 1, Σγ³ = 0) |
| P4C | 3 | комплексный тройной прыжок, γ₁ = 1/(2 − 2^{1/3} e^{2πi/3}) ≈ 0.324 + 0.135i, γ₂ ≈ 0.351 − 0.269i |
| P4R | 3 | вещественный тройной прыжок Йошиды (γ₂ ≈ −1.70) — для сравнения |
| P6C | 9 | вложенный комплексный тройной прыжок (4→6: w = e^{4πi/5}); все Re γ > 0 |
| P6R | 9 | вложенный вещественный тройной прыжок — для сравнения |

Для вещественной задачи после каждого шага композиции берётся Re(y).

**Тестовые задачи:** гармонический осциллятор; линейная система в форме Фробениуса (коэффициент асимметрии k = 0, худший случай для KD); скалярная логистическая; Ван дер Поль μ = 1; Лотка–Вольтерра; Кеплер e = 0.5 (один период); Лоренц (T = 1); вынужденный Дуффинг (неавтономная). Эталон: точное решение или DOP853 с rtol ≈ 2e-14.

## Результаты (эксперимент 1)

Наблюдаемый порядок, медиана по 8 задачам (наклон по 4 самым мелким шагам до плато округления; полные данные в `results/orders_table.md`, `results/errors.csv`):

| опора | P2 | P3C | P4C | P4R | P6C | P6R |
|---|---|---|---|---|---|---|
| trapezoid | 2.00 | 4.00 | 4.00 | 4.00 | 6.03 | 5.99 |
| KD | 2.00 | 4.00 | 4.00 | 4.00 | 6.03 | 6.00 |
| midpoint | 2.00 | 4.00 | 4.00 | 4.01 | **4.99** | **5.00** |

Графики: `results/fig_order_<задача>.png` (ошибка от h), `results/fig_cost_vanderpol.png`, `results/fig_cost_kepler.png` (ошибка от числа вычислений f).

Оценки для P6C по отдельным задачам шумные (от 5.6 до 8): у комплексной схемы константа ошибки на 3–4 порядка меньше, чем у вещественной, и ошибка упирается в округление (~1e-13) уже при N ≈ 100–300, так что асимптотический участок короткий. Медиана и графики показывают порядок 6.

## Диагностика (эксперимент 2, `results/diagnostics.md`)

Дефект симметричности ‖Φ_{−h}(Φ_h(y₀)) − y₀‖:

| метод | порядок дефекта |
|---|---|
| trapezoid, KD(0.5) | 0 (на уровне 1e-17) — симметричны |
| KD(s = 0.3) | h² |
| midpoint, 1 подшаг (= метод Хойна) | h⁴ |
| midpoint, 2 или 4 подшага | **h⁶** |

Другие наблюдения:
- KD(0.5) и трапеции на скалярной задаче дают побитово одинаковый результат, как и предсказывал конспект.
- У midpoint с нечётным числом подшагов (1, 3) композиции дают только порядок 3, с чётным (2, 4) — 4 и 5.
- Отключение проекции Re после каждого шага на порядок не влияет (Re всё равно берётся на выходе).

## Выводы по вопросу 1 (предварительно)

1. **Трапеции и KD (s = 0.5)** — симметричные опоры: все схемы дают заявленный порядок 2/4/6, с комплексными и вещественными коэффициентами.
2. **Модифицированная средняя точка со сглаживанием** — несимметрична, но «почти симметрична»: при чётном числе подшагов первый несимметричный член модифицированного поля имеет порядок h⁶. Поэтому порядок 4 достигается, а порядок 6 — **нет** (получается 5): тройной прыжок обнуляет Σγ³ и Σγ⁵, но не Σγ⁶, который и стоит при несимметричном члене. При нечётном числе подшагов (в т. ч. метод Хойна) несимметричный член уже h⁴, и порядок ограничен 3.
3. Отсюда прямая постановка для вопроса 4: для midpoint нужна палиндромная схема с Σγ = 1, Σγ³ = 0, Σγ⁵ = 0 **и Σγ⁶ = 0**. Это 4 комплексных уравнения, значит нужно ≥ 4 свободных коэффициента (палиндром из 7 стадий). Такие коэффициенты можно искать решением полиномиальной системы или оптимизацией.
4. Двухстадийная схема P3C на симметричной опоре даёт 4, а не 3. Вероятное объяснение: ведущий член ошибки h⁴ у неё чисто мнимый, и его убивает взятие Re. Это стоит проверить аналитически.
5. На крупных шагах вещественные схемы (отрицательный γ₂) разваливаются раньше комплексных, особенно на явной опоре. Это задел для вопроса 3 об устойчивости.
