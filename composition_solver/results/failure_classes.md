## B. Правая часть из таблицы (np.interp)

- np.interp(1+1j, ...) с питоновским complex: `TypeError: float() argument must be a string or a real number, not 'complex'`
- np.interp(np.complex128(1+1j), [0, 2], [0, 2]) = np.float64(1.0): мнимая часть молча отбрасывается.
- Внутри решателя время стадии t + γh комплексное (numpy-скаляр), так что табличная f получает неверный аргумент без всякой ошибки.
- P4R, 50 шагов: y(5) = -0.340923
- P4C, 50 шагов: y(5) = -0.340678
