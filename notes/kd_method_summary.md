# Метод KD (CD, composition-diagonal): конспект статьи

**Статья:** M. Galchenko, V. Sheptunova, A. Karimov, E. Kopets, S. S. Muni, D. Butusov. *New Approaches to Stability Analysis for Semi-Implicit Numerical Integration Methods.* Mathematics 2026, 14, 231. doi:10.3390/math14020231. Группа Д. Н. Бутусова из СПбГЭТУ «ЛЭТИ» (кафедра САПР и Молодёжный НИИ). Переписка: dnbutusov@etu.ru.

**Важно:** «KD» в постановке задачи и «CD» в статье означают один и тот же метод, композиционный диагональный (КД). Сама статья метод не выводит, а исследует его устойчивость. Первоисточники метода:
- [5] Butusov, Ostrovskii, Pesterev, EIConRus 2017: исходный CD и D-метод;
- [6] Ostrovskii, Rybin, Karimov, Butusov, *Chaos Solitons Fractals* 2022: CD с переменной симметрией s;
- [7] Rybin et al., *Mathematics* 2025, 13, 1229: адаптивный шаг и коэффициент искажения симметрии;
- [16] Fedoseev, Karimov, Legat, Butusov, *Mathematics* 2022, 10, 4327: области устойчивости полуявных композиционных схем. Эту работу стоит прочитать следующей.

## 1. Формулы

Система записывается покомпонентно, x₁' = f₁(x₁, x₂), x₂' = f₂(x₁, x₂). В статье везде 2 компоненты. На n компонент метод обобщается так: в первой половине проход идёт по компонентам вперёд, во второй в обратном порядке.

**Полушаг 1, метод Эйлера–Кромера (полуявный, порядок 1, шаг h₁ = s·h).** Каждая компонента обновляется явно и сразу использует уже обновлённые значения:

```
x1_{n+s} = x1_n + h1 * f1(x1_n,   x2_n)
x2_{n+s} = x2_n + h1 * f2(x1_{n+s}, x2_n)
```

**Полушаг 2, D-метод (диагонально-неявный, порядок 1, шаг h₂ = (1−s)·h), компоненты в обратном порядке:**

```
x2_{n+1} = x2_{n+s} + h2 * f2(x1_{n+s}, x2_{n+1})    <- неявно только по x2
x1_{n+1} = x1_{n+s} + h2 * f1(x1_{n+1}, x2_{n+1})    <- неявно только по x1
```

Каждое уравнение неявно только по своей переменной. Поэтому вместо системы нужно решать n скалярных уравнений, а в линейном случае хватает деления на (1 − h₂·a_ii); см. формулу (25) статьи.

При s = 0.5 получается классический симметричный CD (формула (1) статьи). При s = 0 остаётся чистый D-метод, при s = 1 чистый Эйлер–Кромер.

## 2. Порядок, симметричность, сопряжённость

- Эйлер–Кромер (Φ_h) и D-метод в обратном порядке образуют **пару сопряжённых методов**: Φ\*_h = Φ_{−h}⁻¹. Я проверил это сам, обращая Эйлера–Кромера с шагом −h: получаются ровно формулы D-полушага. Схема та же, что у Штёрмера–Верле, которого собирают из симплектического Эйлера и его сопряжённого (Hairer–Lubich–Wanner).
- **CD = Φ\*_{h/2} ∘ Φ_{h/2}** является **симметричным (самосопряжённым) методом 2-го порядка**. Только в этом случае его можно брать опорным для симметричных композиций (triple jump, Suzuki, SS05 и т. п.).
- При s ≠ 0.5 метод несимметричен и имеет **порядок 1** («integrators of order 1 with arbitrary digital dissipativity»). Параметр s управляет цифровой диссипацией дискретной модели; авторы используют это для хаотических систем.
- Мои выводы, которых в статье нет:
  - **Для скалярного ОДУ (n = 1)** Эйлер–Кромер совпадает с явным Эйлером, а D-метод с неявным, поэтому **CD(s = 0.5) совпадает с методом трапеций** (y₁ = y₀ + h/2·(f(y₀) + f(y₁))). При n ≥ 2 и связанных компонентах методы различаются. Это полезно для сравнения опорных методов в проекте.
  - **Для разделимых систем** (f₁ зависит только от x₂, f₂ только от x₁) D-полушаг становится явным, и CD превращается в Штёрмера–Верле (leapfrog).
  - **Результат зависит от порядка нумерации переменных**, это свойство метода.

## 3. Устойчивость (основной вклад статьи)

- Скалярная тестовая задача Далквиста x' = λx к полуявным методам **неприменима**, потому что в ней нечего «расщеплять». Нужна тестовая задача хотя бы 2-го порядка X' = AX с собственными числами σ ± iω.
- Матрица A параметризуется (формулы (10)–(16)) через **коэффициент асимметрии k = a/d** и r = b/c, где r на форму области не влияет. При k = 1 матрица в нормальной жордановой форме вида [[σ, ω], [−ω, σ]], при k = 0 во фробениусовой (сопровождающей) форме, то есть «вырожденный» худший случай.
- Матричная функция устойчивости R(hλ) находится так: метод применяется покомпонентно к матрице R с начальным значением R₀ = I (формулы (21)–(25)). Критерий устойчивости: m = max|eig R| ≤ 1. Для композиции нужно взять произведение R(h_St λ)⋯R(h₁λ), то есть просто прогнать все стадии подряд. В приложении приведён готовый код на MATLAB.
- **Результаты:**
  - У явных методов (Эйлер, RK2) область от k не зависит. **У полуявных она сильно зависит от асимметрии системы.**
  - CD (s = 0.5): при k = 1 область устойчивости представляет собой широкую полосу вдоль отрицательной вещественной оси с |Im hλ| ≲ 2. При k = 0 она сжимается до ограниченной области примерно [−2, 0] × [−2, 2]. **Значит, CD не A-устойчив**, мнимая ось покрыта только на отрезке |Im| ≲ 2.
  - D-метод (s = 0) авторы называют **A(α)-устойчивым** и отмечают, что раньше это не показывалось. Эйлер–Кромер (s = 1) имеет маленькую область. Промежуточные значения s дают промежуточный вариант; при s < 0.5 появляются области устойчивости в правой полуплоскости, то есть метод «пересглаживает».
  - Для экстраполяции CD (последовательности Ромберга, Булирша, Штеттера и т. д.) первые стадии сначала уменьшают область, а дальнейшие её расширяют.
  - **У композиций CD** (triple jump; 10-й порядок SS05 с 31/33/35 стадиями, HLW02, KR97, TSI99) область устойчивости получается **фрагментированной, изрезанной, из множества слабо связанных кусков**. Авторы прямо называют это существенным недостатком для практики.

## 4. Что важно для композиций с комплексными коэффициентами

1. **Опорным для симметричных схем годится только CD с s = 0.5.** Тогда классическая теория симметричных композиций (порядок 2 → 4 → 6, условия только на нечётные моменты) применима без изменений. Это сразу даёт ответ на вопрос 1 для KD.
2. **Комплексные шаги допустимы технически.** D-полушаг в линейном случае сводится к делению на (1 − γh·a_ii), и при комплексном γ знаменатель не обращается в ноль, если a_ii вещественно и Im γ ≠ 0. В нелинейном случае скалярные неявные уравнения решаются Ньютоном в комплексной арифметике. Для вещественной задачи после шага нужно брать Re (проекция). Стоимость при этом примерно удваивается.
3. **Мотивация комплексных коэффициентов видна прямо из статьи.** У вещественного triple jump средний коэффициент отрицателен (≈ −1.70). При отрицательном шаге D-полушаг ведёт себя как «явный», и область устойчивости разваливается: это и есть изрезанные области на рис. 10b, 13 и 14. Комплексные коэффициенты с Re γ > 0 (например, γ = 1/(2 − 2^{1/3}e^{2πi/3})) по идее должны это исправлять. **Это и есть проверяемая гипотеза для вопроса 3.**
4. **Метод анализа устойчивости переносится напрямую.** Строим R для каждой стадии с комплексным шагом h_i = γ_i h, перемножаем и смотрим max|eig| на сетке (σ, ω) при разных k. Нужно обязательно смотреть не только k = 1, но и k = 0: в худшем случае асимметрии у CD области устойчивости ограничены.
5. **Для вопроса 4 (несимметричная опора).** CD(s) при s ≠ 0.5 сам по себе композиция Φ и Φ\* с шагами sh и (1−s)h; порядок 2 достигается только при s = 0.5, и комплексные s тут не помогают (условие a² = b² при a + b = 1). Для несимметричного метода порядка p общая теория (Hansen–Ostermann 2009, Castella–Chartier–Descombes–Vilmart 2009, Blanes–Casas–Chartier–Murua 2013) требует ещё и условия на Σγ^{p+1}. Например, для p = 2 две стадии с γ₁,₂ = 1/2 ± i/(2√3) дают порядок 3. Дальше условий становится больше, и здесь как раз имеет смысл численный (нейросетевой или оптимизационный) поиск.
6. **Неточность в статье.** Подпись к рис. 10b называет композицию «D-method (CD with s = 0)», но triple jump даёт порядок 4 только на симметричной опоре (s = 0.5). Либо это опечатка, либо порядок там не 4. Этот рисунок не стоит брать за эталон.
