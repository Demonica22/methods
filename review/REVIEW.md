# Независимое ревью: композиционные схемы с комплексными коэффициентами

Предмет ревью: `composition_solver/` (README.md, RESEARCH.md, csolver/, experiments/, results/) и конспект `notes/kd_method_summary.md`.
Все проверки сделаны своим кодом (`review/*.py`). Пакет `csolver` не импортируется. Из `results/coeff_search.json` взяты только числа коэффициентов.

Чем проверка отличается от работы автора:

- **Порядок по локальной ошибке считается в высокой точности** (mpmath, 50 знаков). Точный поток берётся из ряда Тейлора (`mpmath.odefun`). Поэтому ошибка округления не влияет и асимптотика видна до ошибок 1e-27.
- **Задачи:** 6 нелинейных, в том числе неавтономные. Задачи generic3 (3-мерная, сильно связанная, неполиномиальная, неавтономная) у автора не было.
- **Условия порядка проверяются точно**, через свободную ассоциативную алгебру (слова). Случайные матрицы не используются.
- **Функция устойчивости трапеций выписана аналитически.** A-устойчивость проверяется по принципу максимума.

## 0. Краткая сводка

### Главные найденные ошибки (по убыванию важности)

1. **Достаточное условие A-устойчивости (RESEARCH.md, вопрос 3) в заявленной общности неверно.** Доказательство опирается на шаг «полюса r(γᵢz) лежат в правой полуплоскости». Из A-устойчивости r и Re γᵢ > 0 он следует только тогда, когда полюса r вещественны (как у трапеций). Для полюсов вне вещественной оси нужно |arg γᵢ| + |arg w_pole| < 90°.
   - Контрпример 1: метод Гаусса–Лежандра с 3 стадиями (симметричен, A-устойчив, коэффициенты r вещественны) в композиции с P6SC самого автора. У R(z) есть полюс z ≈ −0.41 ± 20.04i в левой полуплоскости, |R| ≈ 29 рядом с ним. При этом |R(iy)| ≡ 1, то есть проверка «по мнимой оси» эту неустойчивость не видит.
   - Контрпример 2: Гаусс-2 ∘ {1/2 ± 1.5i}, полюс z ≈ −0.44 ± 2.15i.
   - Для трапеций вывод верен: P3C и P6SC A-устойчивы.
   - Данные: `r5_stability.py`, `fig_r5_trap_gauss.png`.
2. **«Порядок 6 у P6SC есть только с проекцией Re после шага, без проекции порядок 3» (RESEARCH.md) — для решателя это неверно.** Если не проецировать на каждом шаге, а взять Re только в конце (так делает `integrate(project_real=False)`), глобальный порядок остаётся 6: 5.99–6.08 на 4 задачах и 2 опорах. Порядок 3 относится только к комплексной локальной ошибке. Её ведущий член чисто мнимый, и в вещественную часть он попадает лишь в квадрате, то есть как h⁶. Это заодно противоречит README («отключение проекции на порядок не влияет»).
   - Реально порядок теряется на **комплекснозначных** ОДУ, где брать Re нельзя: y' = i·y² даёт для P6SC порядок 3.00. Этот класс задач в ответе на вопрос 2 пропущен.
   - Данные: `r4_global_order.py`, `r6_failure.py` (E).
3. **«У всех найденных схем Re γ > 0» (RESEARCH.md, вопрос 4) — ошибка для схемы `general_p4_pal_Re`.** Опубликованные коэффициенты (Re γ₂ = 2.6e-5) точным решением не являются: уточнение Гаусса–Ньютона застревает на невязке 1.4e-15. Палиндромное решение порядка 4 с 3 стадиями существует только при Re γ₂ = 0: γ = (1/2 − i/(2√3), i/√3, 1/2 − i/(2√3)). Невязка растёт как (Re γ₂)², например 3e-9 при Re γ₂ = 1e-3. Фактически это чисто мнимый средний шаг. Данные: `r2_order_conditions.py`, разд. 3; разведка в тексте ниже.
4. **Методика оценки наблюдаемого порядка ненадёжна.** Таблица `orders.csv` содержит артефакты: 13.02, 8.12, 7.36, 6.57, 3.61, 3.51. Медиана по задачам их прячет. Причины две: у P6C на трапециях константа ошибки крайне мала (линейный коэффициент 1.4e-10 при z⁷), и асимптотического участка между пред-асимптотикой и плато округления почти нет; кроме того, у Кеплера (P4R/P6C на midpoint) режим ещё не асимптотический. Итоговые порядки в таблицах RESEARCH.md при этом верны: проверка в высокой точности даёт 2/4/4/4/6/6/6 и 2/4/4/4/5/5/5 без исключений (`r3_local_order.py`).
5. **Класс 3 в ответе на вопрос 2 («слабо затухающие колебания, hω ≈ 5–30, не жёсткие») описан неточно.** Сам механизм (не A-устойчивые P4C/P6C) подтверждён количественно: амплитуда совпадает с |μ(hλ)|^N до 3 знаков. Но при hω ≥ 5 колебание сеткой не разрешено, и ни один метод, включая опорные трапеции, не даёт там точности: амплитуда 0.9–0.99 при точной 0.45. Это колебательно-жёсткий режим. Корректная формулировка: «с крупным относительно быстрой моды шагом P4C/P6C раскачивают моду вместо того, чтобы её демпфировать».
6. **Найденные коэффициенты опубликованы с точностью около 1e-7, а не 1e-15.** Система условий вырождена, решения образуют семейства. Уточнение сдвигает коэффициенты на 5e-8…2e-7 при исходной невязке около 1e-16 (`r2`, разд. 3). На двойную точность это не влияет, но при ошибках ниже 1e-19 видно плато. Уточнённые значения лежат в `data/polished.json`.
7. Мелочи:
   - «5-стадийная схема общего вида» для средней точки (`midpoint_p6_gen_Re`) после уточнения оказывается **точно симметрично-сопряжённой** (γ₅ = conj γ₁, γ₄ = conj γ₂, γ₃ ∈ ℝ). Поиск в классе симметрично-сопряжённых схем находит её как единственное решение.
   - Новизну P6SC («найдена в этой работе») без сверки с литературой утверждать нельзя: симметрично-сопряжённые композиции уже исследовались (Blanes–Casas–Chartier–Escorihuela-Tomàs, 2022).
   - Логическая ошибка: «тройной прыжок не удовлетворяет достаточному условию, поэтому теряет A-устойчивость». Невыполнение достаточного условия ничего не доказывает, хотя численно P4C/P6C действительно не A-устойчивы.

Большая часть остальных утверждений подтвердилась независимо. Это реализации опорных методов, свойства симметрии, порядки 2/4/6 для трапеций и KD, порядок 5 для средней точки, области устойчивости KD, углы A(α), существование коэффициентов для несимметричных опор и классы A, B, D из вопроса 2.

### Итоговые ответы на вопросы 1–4 (по данным ревью)

**1. Для каких опор достигается заявленный порядок?**
- **Трапеции и KD (s = 0.5)** симметричны: дефект ‖Φ₋ₕ∘Φₕ − id‖ ≈ 1e-61 при 60 знаках. Все симметричные схемы дают 2/4/6: P4C, P4R, P6C, P6R, а также P6SC с проекцией Re.
- **Средняя точка Грэгга (2 подшага + сглаживание)** почти симметрична (дефект h⁶, т.е. F₄ = 0) и даёт 2/4/**5**: порядок 6 стандартными схемами не достигается.
- **Хойн и обычная явная средняя точка** (дефект h⁴): все стандартные схемы дают только **3**.
- KD при s ≠ 0.5 имеет порядок 1.
- P3C на симметричной опоре и на Грэгге даёт 4, причём только за счёт проекции Re.

**2. Есть ли класс нежёстких задач, которые не решаются?** Да.
- (а) Неаналитическая правая часть (|y|, таблицы, if/max): комплексные схемы опускаются до порядка **2**.
- (б) Комплекснозначные ОДУ, где проекцию Re применить нельзя: P3C, P6SC и найденные схемы «*_Re» теряют порядок (P6SC: 3, midpoint_p6_gen_Re: 3). Этот класс у автора пропущен.
- (в) KD на системах в форме Фробениуса (k = 0) с умеренными |hλ|: область устойчивости ограничена, примерно [−2,0]×[−2,2].
- (г) Колебательно-жёсткие слабо затухающие моды при крупном шаге: P4C и P6C на трапециях раскачивают моду. Это скорее умеренная жёсткость, чем нежёсткая задача.

**3. Сохраняет ли композиция A-устойчивого метода A-устойчивость?** В общем случае **нет**.
- Трапеции с проекцией Re:
  - P4C: A(89.54°), sup|μ(iy)| = 1.0184 при y ≈ 10.1;
  - P6C: A(87.36°), sup = 1.404 при y ≈ 26.3;
  - P4R/P6R: полюса на отрицательной полуоси.
- **Да** для трапеций при наборе γ, замкнутом относительно сопряжения, с Re γᵢ > 0 (P3C, P6SC).
- Общее «достаточное условие» RESEARCH.md неверно: контрпример Гаусс-3 ∘ P6SC.
- KD и средняя точка не A-устойчивы уже как опоры.

**4. Существуют ли коэффициенты для несимметричной или почти симметричной опоры?** **Да**, это подтверждено на нелинейных и неавтономных задачах (порядок 6.00 ± 0.02 в высокой точности, `r3 found`):
- для Грэгга-2 порядок 6 даёт 5-стадийная симметрично-сопряжённая схема (с Re), 7-стадийный палиндром (с Re) и 9-стадийный палиндром (без Re);
- для любой несимметричной опоры 2-го порядка (Хойн и явная средняя точка) порядок 4 дают 3 стадии (с Re) или 4 (без Re), порядок 6 — 7 стадий (с Re);
- схемы для Грэгга на Хойне и явной средней точке дают только 3; это ожидаемо, они строились под F₄ = 0.

Заявленные минимальные числа стадий моими поисками (1500 стартов на случай) **не опровергнуты**, но и не доказаны.

## 2. Коэффициенты и условия порядка (`rv_words.py`, `r2_order_conditions.py` → `out/r2_order_conditions.txt`)

Коэффициенты P4C, P4R, P6C, P6R, P3C я пересчитал независимо по формулам тройного прыжка (50 знаков). Моменты: Σγ = 1; Σγ³ = 0 (до 1e-50); для P6C и P6R также Σγ⁵ = 0. У P6SC (14 знаков из RESEARCH.md) Σγ³ = 1.4e-15, это ошибка округления опубликованных цифр, после уточнения 1e-50. Все Re γ у P6C положительны (min 0.0833), как и заявлено.

Порядок я считал по точным условиям: совпадение коэффициентов всех слов степени ≤ 7 у Ψ_h и exp(hF₁). Для Re-проекции требуется совпадение вещественных частей. Это корректно и для нелинейной задачи: Re Ψ_h(y) = Σ Re(c_w)·D_w Id(y).

## 5. Доказательство достаточного условия A-устойчивости (RESEARCH.md, вопрос 3)

Разбор по строкам:
1. «r(−z) = 1/r(z), r(z̄) = conj r(z)» верно для симметричной опоры с вещественными коэффициентами.
2. «Полюса r(γᵢz) лежат в правой полуплоскости» — **не следует из условий.** Полюс r(γz) находится в z = w_p/γ, где w_p — полюс r, Re w_p > 0. При этом Re(w_p/γ) = (Re w_p·Re γ + Im w_p·Im γ)/|γ|², и это выражение отрицательно при достаточно большом |Im γ|, если Im w_p ≠ 0.
3. «На мнимой оси |r(γ̄iy)| = 1/|r(γiy)|, значит |R(iy)| = 1» — верно.
4. «По принципу максимума достаточно мнимой оси» — верно только при отсутствии полюсов в левой полуплоскости (см. п. 2).

**Контрпримеры** (`r5_stability.py`, разд. 3):
- Гаусс-3, r = Padé(3,3), полюса 4.644 и 3.678 ± 3.509i (arg 43.6°), в композиции с P6SC (arg γ₂ = −47.5°): полюс R в z = −0.4118 ± 20.0418i, |R(−0.4122 + 20.0619i)| = 28.8, хотя sup|R(iy)| = 1.000000000000;
- Гаусс-2 с γ = 1/2 ± 1.5i: полюс z = −0.4392 ± 2.1464i, |R| = 236 рядом с ним.

**Исправленная формулировка:** условие достаточно, если все полюса r вещественны (трапеции, Padé(1,1)) или |arg γᵢ| + max|arg w_p| < 90°. **Вердикт: ошибка в общей формулировке; частный вывод для трапеций (P3C, P6SC) верен.**
